# Advanced Data Professional Learning Path

## Overview

**StoryBoard Analytics Learning Journey** 🐗

**Target Learner:** Intermediate-level Python developer
**Focus Areas:** data_engineering, data_science, visualization
**Time Commitment:** 3 hours/week over 24 weeks
**Learning Style:** Project Based

**Learning Goals:**
- Build production data systems
- Master distributed computing
- Create data visualizations

## What You'll Build

Throughout this learning path, you'll build **real-world data systems** for StoryBoard Analytics 🐗, a fictional multi-channel bookstore:

1. **Real-Time Book Sales Analytics Pipeline**
   - Build a streaming pipeline processing book sales events in real-time
2. **Distributed Customer Analytics with Dask**
   - Analyze millions of customer interactions using distributed computing
3. **Statistical Analysis & Hypothesis Testing**
   - Perform statistical analysis and hypothesis testing on book sales data
4. **Production Data Mesh Implementation**
   - Design and implement data mesh architecture for StoryBoard Analytics

## Project 1: Real-Time Book Sales Analytics Pipeline

**Duration:** 14-15 weeks (41 hours)
**Difficulty:** Intermediate
**Type:** Streaming Pipeline

### Overview

Build a streaming pipeline processing book sales events in real-time

### Skills You'll Practice

- **Stream Processing Fundamentals** (intermediate)
  - Key concepts: event ordering, latency, stream ingestion
- **Materialized Views Construction** (intermediate)
  - Key concepts: incremental updates, CDC, upsert operations
- **Change Data Capture (CDC)** (intermediate)
  - Key concepts: change tracking, event sourcing, Debezium integration
- **Push vs Pull Queries** (beginner)
  - Key concepts: continuous query, on-demand query, latency trade-offs
- **Serving Synchronous and Asynchronous Data** (intermediate)
  - Key concepts: latency management, query concurrency, data freshness

### Project Deliverables

**Detailed Spec:** See `projects/01-real-time-book-sales-analytics-pipeline/README.md`

**What You'll Build:**
- Functional streaming pipeline

- Unit and integration tests
- Performance benchmarks

### Success Criteria

- ✅ All functional requirements implemented

- ✅ Tests pass with >80% coverage
- ✅ Meets performance targets
- ✅ Documentation complete (README + architecture)
